# 🧑‍💻 Rubén — Notas personales

## 🎯 Tarea principal

**Diseño y fabricación de la estructura 3D para el ROSbot 2R (bandeja porta-platos estilo gato sushi)**

## 📋 Subtareas

- [ ] **Tomar medidas del ROSbot 2R**
  - [ ] Medir las dimensiones del chasis (largo, ancho, alto)
  - [ ] Identificar puntos de anclaje / tornillos disponibles en la parte superior
  - [ ] Medir el peso máximo que soporta el robot (consultar specs: ~4 kg de carga útil)

- [ ] **Diseño conceptual de la estructura**
  - [ ] Decidir el tipo de bandeja (plana, con bordes, con compartimentos)
  - [ ] Definir cuántos platos debe llevar a la vez (1-2 platos recomendado)
  - [ ] Diseñar sistema antideslizante para que los platos no se muevan
  - [ ] Pensar en la estética de gato sushi 🐱 (orejas, cara, decoración)

- [ ] **Modelado CAD**
  - [ ] Elegir herramienta de diseño (FreeCAD, Fusion 360, Onshape, TinkerCAD...)
  - [ ] Modelar la base de la bandeja con agujeros de montaje al ROSbot
  - [ ] Modelar los bordes/paredes de contención para los platos
  - [ ] Modelar las piezas decorativas (cabeza de gato, etc.)
  - [ ] Exportar a `.STL` para impresión 3D

- [ ] **Verificación del diseño**
  - [ ] Comprobar que la estructura no tapa los sensores (LiDAR, cámara, ToF)
  - [ ] Verificar que el centro de gravedad no desestabiliza el robot
  - [ ] Comprobar que las dimensiones permiten pasar entre las mesas del restaurante
  - [ ] Revisar que no interfiere con la ventilación de la Raspberry Pi

- [ ] **Impresión 3D y montaje**
  - [ ] Imprimir las piezas (material recomendado: PLA o PETG)
  - [ ] Lijar y ajustar las piezas si es necesario
  - [ ] Montar la estructura sobre el ROSbot 2R
  - [ ] Probar estabilidad con peso real (platos con comida de prueba)

- [ ] **Iterar según pruebas**
  - [ ] Ajustar diseño si hay problemas de estabilidad, altura o interferencia con sensores
  - [ ] Versión final documentada con fotos y medidas
