# 📋 Información del Proyecto — PR2026

## Descripción

Proyecto de robótica basado en el **iRobot Create 3** programado con **ROS2**. El objetivo es desarrollar aplicaciones y comportamientos autónomos para el robot utilizando el ecosistema de ROS2.

| Manu   | [Manu.md](Manu.md) |

## 🎯 Objetivos

1. Aprender a utilizar ROS2 para el control del iRobot Create 3.
2. Desarrollar nodos de ROS2 para la lectura de sensores y actuación sobre el robot.
3. Implementar comportamientos autónomos (navegación, evitación de obstáculos, etc.).
4. Documentar todo el proceso de desarrollo y los errores encontrados.
